## Decisions
- Data source: SofaScore's internal API via `curl_cffi` (`impersonate="chrome"`), not FBref/Transfermarkt directly — see below.
- One shared Elo pool across all 7 competitions, not per-league — needed so Champions/Europa League matches calibrate ratings across different domestic leagues.
- No separate cache/state files — `matches.csv` and `elo.csv` are the single source of truth; current ratings are always derived from `elo.csv`, never stored separately. Avoids state going stale.
- Match identity = `(date, home_team, away_team)` — good enough, skipped using SofaScore's numeric match IDs.
- Data CSVs are committed to git (not gitignored) — want history of how data/ratings evolved.

## Problems & how we solved them
- SofaScore/FBref/Transfermarkt all block plain `requests`/`curl` (403 or Cloudflare JS challenge) → `curl_cffi` with `impersonate="chrome"` gets past SofaScore and Transfermarkt (TLS-fingerprint check only); FBref still blocks — it's a real interactive JS challenge, needs an actual browser.
- `compute_elo()` was updating ratings out of chronological order (matches weren't globally sorted by date before processing, only grouped by competition) → fixed by sorting before the update loop. Had to delete and rebuild `elo.csv` from scratch since the existing history was corrupted.
- Reused the variable name `cols` across multiple notebook cells → wrong columns displayed depending on what order cells were run in. Fixed by giving each its own name (`browse_cols`, `upset_cols`). General lesson: don't reuse generic variable names across notebook sections.

## What we learned (from real data)
- Overall win/draw/loss accuracy is ~47.6% — essentially a coinflip. The model only earns its keep once there's a real rating gap.
- Elo accuracy scales with rating gap up to a point: ~40% near 0, climbing to ~78-82% around a 200-point gap. Past 200 the sample thins out fast (19, 8, 0 matches per 50-point bucket) so it's a plateau we can trust up to ~200-250, not a confirmed continued climb beyond that.
- Rolling accuracy over time does NOT monotonically improve — there's no K-decay, so no real "stabilization" as more matches accumulate.
- Predicting "draw" for close matches (Elo near 50%) makes accuracy worse, not better — draws are only ~23% of matches even among evenly-matched teams.
- "Double chance" (home win-or-draw, when Elo favors home) is much stronger than "home win only": ~79% vs ~55% accuracy.
- Plain Elo underpredicts home wins vs reality — real split ~46/23/31 (home/draw/away), Elo predicts ~48/52 home/away — concrete evidence we should add a home-advantage term.

- The "47.6% ≈ coinflip" framing was misleading — it's diluted by draws (23.5% of matches, always misses for a binary home/away picker). `overall accuracy = (1 - draw_rate) × decisive_accuracy` (76.5% × 62.2% = 47.6%, exact). Decisive-match accuracy (62.2%) is the honest measure of how good the model is at its actual job.
- Better home-advantage evidence than the earlier 48/52-vs-46/23/31 comparison (which was apples-to-oranges): controlling for "who's rated higher," home favorites win 72.7% of decisive matches vs away favorites winning only 52.5%. Same signal (being the better-rated team), 20pp swing from venue alone.
- Draws don't correlate with closeness the way you'd expect — draw rate is flat (~24%) across Elo gaps up to ~130-150, only dropping for genuinely lopsided matches. What actually predicts draws: **average team strength**, not gap. Weak-team matchups draw ~27-31%, strong-team matchups only ~15-17%. Confirmed via a 2D heatmap (strength × gap) that strength dominates, not gap.
- Directly measured home advantage from outcomes: home/away win-rate curves (vs signed Elo gap) cross at gap ≈ -38, i.e. home needs to be ~38 points weaker before away becomes the more likely winner. More grounded than a guessed constant.
- Home advantage looks fairly constant across team-strength levels, but varies by competition — Champions League has the strongest home tilt (~52% home / ~30% away), Serie A the most balanced (~40% home / ~35% away).
- Draw-band prediction (predict "draw" for near-50% matches) still loses to never-predict-draw whether or not home advantage is factored in — consistent conclusion both ways. Home advantage adjustment alone (no draw band) raised 2-way accuracy from 46.9% to 49.5%.

6. Model family: gradient-boosted trees (XGBoost/LightGBM) are the natural fit once the feature set is this heterogeneous (mixed numeric/categorical, many engineered features, moderate data size) — better suited here than a neural net (too data-hungry for ~3-5k matches) or extending Elo further (hits diminishing returns).
