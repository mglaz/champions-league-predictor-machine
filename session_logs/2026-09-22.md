# Session log — 2026-09-22

First entry, covering everything built so far (spans several working sessions).

## Data pipeline
- Scrape match data (fixtures + results) from SofaScore's internal API using `curl_cffi` with `impersonate="chrome"` — needed to get past SofaScore's TLS-fingerprint bot blocking (plain `requests`/`curl` get a 403; a real Chrome TLS fingerprint gets through).
- Covers 7 competitions × 2 seasons: Champions League, Europa League, Premier League, La Liga, Bundesliga, Serie A, Ligue 1 (2025/26 and 2026/27).
- `matches.csv` is the cache; the loader checks for new matches since the latest cached date per competition and only fetches what's missing (`fetch_new_events`, pages backward until it hits already-known matches).

## Elo rating system
- Plain Elo (`K=20`, no home advantage or goal-margin adjustment yet) computed across all competitions in one shared rating pool, so Champions/Europa League matches calibrate ratings across different domestic leagues.
- `elo.csv` caches per-match before/after ratings; `compute_elo()` figures out which matches are new (missing Elo columns) and only processes those, rebuilding the live `ratings` dict from already-computed rows.
- **Bug found and fixed**: `compute_elo()` wasn't sorting matches by date before processing, so ratings were being updated out of chronological order (matches from different competitions interleaved incorrectly). Fixed by sorting before the update loop; `elo.csv` was deleted and fully rebuilt.

## Predictions
- `fetch_upcoming()` pulls the next Champions League round's fixtures and predicts each with a win-lean percentage from the Elo gap.

## EDA / model evaluation (all against real data, not cherry-picked)
- Accuracy vs Elo gap: rises from ~40% (small gaps) to ~85% (200+ point gaps).
- Rolling accuracy over time does **not** cleanly improve — drifts up then back down, consistent with no K-decay for experience.
- Home advantage: real matches split ~46% home / 23% draw / 31% away, but plain Elo (no home boost) predicts an almost even 48/52 home/away split — a concrete case for adding a home-advantage term later.
- Tried predicting "draw" for close matches (Elo prob near 50%) — this **hurts** accuracy, monotonically, the wider the band.
- "Double chance" (home win-or-draw when Elo favors home) works well: ~77% accuracy overall, up to ~94% at big gaps.
- Calibration curve is reasonably close to the diagonal but slightly underconfident, consistent with the missing home-advantage term.
- Biggest upsets (after both teams have 10+ rated matches): Brighton 3-0 Arsenal (this season), Hellas Verona 3-1 Atalanta, Bayern Munich losing to Augsburg.
